# Fonts for 3D Text

For the 3D text to work properly, you need to add a typeface.json font file.

You can:
1. Download from: https://github.com/mrdoob/three.js/tree/master/examples/fonts
2. Use the `gentilis_bold.typeface.json` file
3. Place it in this `/public/fonts/` directory

Or use the CDN approach by updating the font path in WonderModel.jsx to:
```
https://threejs.org/examples/fonts/gentilis_bold.typeface.json
```
